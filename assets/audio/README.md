# Sounds and music

Every file in this folder is generated by `tools/make_audio.py` from simple
waveforms and noise. There are no samples, recordings or third-party sound
packs, so all of it is original to this project.

To change a sound, edit its function in `tools/make_audio.py` and run:

```
python tools/make_audio.py            # all sounds
python tools/make_audio.py jump star  # just these
```

(Needs Python 3 with `numpy` and `scipy`. `ffmpeg` is optional; with it the
music is saved as small `.ogg` files.)

## How the game finds sounds

Gameplay code only calls hooks such as `AudioManager.play(&"jump")`. The
AudioManager loads `res://assets/audio/<id>.ogg` or `<id>.wav`. A missing file
is simply skipped, so you can delete, replace or add sounds without touching
any code, and the game always works with the sound off.

| Hook | When it plays |
|---|---|
| `jump`, `land`, `bounce` | Character hops, lands hard, or bounces on a pad or a bouncy floor |
| `bonk` | Bumped by an obstacle |
| `fall_whoosh`, `respawn_pop` | Falling into the goo and popping back at a checkpoint |
| `voice_happy`, `voice_surprised`, `voice_dizzy`, `voice_oops` | Creature reactions (pitched per character) |
| `star`, `score`, `checkpoint` | Collecting a star, scoring points, reaching a checkpoint |
| `countdown`, `go`, `tick` | 3-2-1-GO, last seconds of the round and of a chaos countdown |
| `chaos_announce`, `chaos_start`, `chaos_end` | A rule switch is coming, starts, ends (per-event ids can be set on each chaos event) |
| `cake_grab`, `put_down`, `helper`, `cake_drop`, `splat`, `delivery` | Cake Dash |
| `button_right`, `buzzer`, `wave_done` | Button Mayhem (the "wrong button" sound is a soft, silly bwomp) |
| `finish_line` | Bounce Race |
| `victory`, `round_over` | End of a round (losing gets a friendly "wah-wah", never a harsh sound) |
| `ui_click`, `equip`, `locked` | Menus and the Wardrobe |
| `music_menu`, `music_match` | Looping background music |
